# 🚀 Mini Projects: Statistics

## 1. A/B Test Simulator & Analyzer
**Description:** Create a script that generates mock data for a website's A/B test (e.g., Conversion Rate of Button A vs Button B). The script should then analyze the data, calculate confidence intervals, p-values, and output a recommendation on whether to adopt the new button.
**Skills:** Hypothesis testing, `scipy.stats`, interpretation of p-values.

## 2. Distribution Visualizer App
**Description:** Build a simple Streamlit or purely Matplotlib-based script where a user can select a distribution (Normal, Binomial, Poisson, Exponential), tweak its parameters, and instantly see the PDF (Probability Density Function) and CDF (Cumulative Distribution Function) plotted.
**Skills:** Probability distributions, interactive plotting.

## 3. Statistical Inference Engine
**Description:** Take a real dataset (like the Titanic dataset). Perform rigorous statistical analysis before any machine learning: test if survival rates significantly differ by gender (Chi-square test), check if age distributions differ by class (ANOVA), and compute correlations among numerical features. Summarize findings in a Markdown report.
**Skills:** EDA, statistical tests, interpreting complex datasets.
