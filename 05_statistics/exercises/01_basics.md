# 🏋️ Exercises: Statistics Basics

## Easy (🟢)
1. Write a function from scratch to calculate the mean and median of a list of numbers.
2. Calculate the variance and standard deviation of an array using NumPy.
3. Generate 1000 samples from a normal distribution with mean 50 and std dev 5, and plot its histogram.
4. Calculate the Pearson correlation coefficient between two arrays.

## Medium (🟡)
5. Perform a two-sample t-test using `scipy.stats` to check if two distributions are significantly different.
6. Write a function that calculates the probability of getting exactly $k$ heads in $n$ coin tosses (Binomial distribution).
7. Apply Bayes' theorem in code: Given $P(Disease) = 0.01$, $P(Positive|Disease) = 0.99$, and $P(Positive|No Disease) = 0.05$, calculate $P(Disease|Positive)$.
8. Identify outliers in a Pandas Series using the IQR method.

## Hard (🔴)
9. Simulate the Central Limit Theorem: roll a 6-sided die, take the mean of $N$ rolls. Repeat 10000 times, plot the distribution of means for $N=1, 5, 30$.
10. Formulate an A/B test scenario. Generate mock data for Control and Treatment groups, calculate the lift, and determine if the difference is statistically significant using a z-test.
