# 🏗️ Deep Learning Mini Projects

Put your deep learning knowledge into practice!

## 1. MNIST Digit Classifier
- **Description**: Build a neural network to classify handwritten digits (0-9) from the famous MNIST dataset.
- **Skills Practiced**: Dense neural networks, activation functions, categorical crossentropy, understanding training/validation curves.
- **Starter Instructions**: Start with a simple Multi-Layer Perceptron (MLP) architecture. Experiment with different activation functions (Sigmoid vs ReLU) and observe the training speed.

## 2. Sentiment Analyzer
- **Description**: Train a model to determine whether a movie review is positive or negative.
- **Skills Practiced**: Basic handling of sequential text data, embedding layers, simple RNN or LSTM architecture.
- **Starter Instructions**: Use the IMDB dataset. Pad the sequences to a fixed length and use an Embedding layer followed by a simple Recurrent layer.

## 3. Image Style Transfer (Simplified)
- **Description**: Implement a basic version of style transfer, mixing the content of one image with the style of another.
- **Skills Practiced**: Working with pre-trained models, extracting feature representations, optimization loops based on custom loss functions.
- **Starter Instructions**: Use a pre-trained network like VGG19. You don't need to train a new network; instead, optimize a generated image to minimize content loss and style loss relative to your target images.
