# 🚀 Computer Vision Mini Projects

## 1. Face Detection System
- **Description**: Build a system that can take a photo and draw bounding boxes around all human faces detected.
- **Skills Practiced**: Working with pre-trained detection models (like Haar Cascades or MTCNN), drawing on images with OpenCV or PIL.
- **Starter Instructions**: Start with OpenCV's Haar Cascade classifier for a lightweight solution. Once working, try upgrading to a deep-learning-based detector like MTCNN for better accuracy.

## 2. Plant Disease Classifier
- **Description**: Classify images of plant leaves into different disease categories.
- **Skills Practiced**: Transfer learning with ResNet/EfficientNet, heavy data augmentation, handling class imbalances.
- **Starter Instructions**: Find a dataset like PlantVillage. Use a pre-trained model and experiment with advanced augmentations like random rotations, color jitter, and maybe even mixup to improve robustness.

## 3. Traffic Sign Recognizer
- **Description**: Build a CNN to classify different types of traffic signs from the German Traffic Sign Recognition Benchmark (GTSRB).
- **Skills Practiced**: Building custom CNN architectures, learning rate scheduling, model evaluation.
- **Starter Instructions**: The images are small and varying in size. Preprocess them to a fixed size (e.g., 32x32). Build a custom CNN architecture similar to LeNet but slightly deeper, and train it from scratch.
