# 🏭 Capstone & Production Projects

These projects focus on taking a trained model out of the Jupyter Notebook and into the real world. This is what separates ML Engineers from Data Scientists.

## 1. FastAPI ML Service
- **Description**: Wrap a trained machine learning model (e.g., your House Price predictor) in a REST API.
- **Technologies**: Python, FastAPI, Uvicorn, Pydantic.
- **Key Skills**: API design, request validation, serialization, basic backend development.
- **Estimated Time**: 5-10 hours.

## 2. Docker + CI/CD Pipeline
- **Description**: Containerize your FastAPI service and set up automated testing and building using GitHub Actions.
- **Technologies**: Docker, Docker Compose, GitHub Actions, Pytest.
- **Key Skills**: Containerization, writing Dockerfiles, Continuous Integration, unit testing ML code.
- **Estimated Time**: 8-15 hours.

## 3. MLflow Experiment Tracking
- **Description**: Integrate an experiment tracking tool into your training pipeline to log parameters, metrics, and models.
- **Technologies**: MLflow (or Weights & Biases).
- **Key Skills**: Experiment tracking, model registry, reproducibility, comparing model runs.
- **Estimated Time**: 5-10 hours.

## 4. Streamlit Dashboard
- **Description**: Build an interactive web dashboard to visualize data and allow users to interact with your model without writing code.
- **Technologies**: Streamlit, Pandas, Plotly/Matplotlib.
- **Key Skills**: Frontend for ML, interactive data visualization, state management in Streamlit.
- **Estimated Time**: 6-12 hours.

## 5. End-to-End ML Deployment
- **Description**: Deploy your containerized API and Streamlit frontend to a cloud provider.
- **Technologies**: AWS/GCP/Azure, Heroku, or Render.
- **Key Skills**: Cloud deployment, setting up environments, managing secrets, full-stack ML.
- **Estimated Time**: 15-25 hours.
