# 🌱 Beginner Projects

These projects focus on mastering the fundamentals: data cleaning, basic model implementation, and standard evaluation metrics using Scikit-Learn.

## 1. House Price Prediction
- **Description**: Predict the selling price of houses based on features like square footage, number of bedrooms, and location.
- **Dataset**: Ames Housing Dataset or California Housing.
- **Key Skills**: Exploratory Data Analysis (EDA), handling missing values, Linear Regression, Random Forests, MSE/RMSE.
- **Estimated Time**: 2-4 hours.

## 2. Titanic Survival
- **Description**: The classic Kaggle introductory project. Predict which passengers survived the Titanic shipwreck.
- **Dataset**: Titanic dataset from Kaggle.
- **Key Skills**: Binary classification, feature engineering (extracting titles from names), Logistic Regression, accuracy scoring.
- **Estimated Time**: 3-5 hours.

## 3. Iris Classification
- **Description**: Classify iris flowers into three species based on sepal and petal dimensions.
- **Dataset**: UCI Iris dataset (built into scikit-learn).
- **Key Skills**: Multiclass classification, K-Nearest Neighbors (KNN), Support Vector Machines (SVM), pairplots.
- **Estimated Time**: 1-2 hours.

## 4. Spam Detection
- **Description**: Build a simple NLP model to classify text messages or emails as spam or ham.
- **Dataset**: SMS Spam Collection Dataset.
- **Key Skills**: Text preprocessing, Bag of Words / TF-IDF, Naive Bayes classifier, Precision and Recall.
- **Estimated Time**: 3-4 hours.

## 5. Student Score Prediction
- **Description**: Predict a student's final exam score based on hours studied, previous scores, and other demographic factors.
- **Dataset**: Student Performance dataset.
- **Key Skills**: Simple and Multiple Linear Regression, interpreting coefficients, visualizing relationships.
- **Estimated Time**: 2-3 hours.
