# 🏋️ Exercises: Visualization Basics

## Easy (🟢)
1. Plot a simple line graph of $y = x^2$ for $x$ from -10 to 10.
2. Create a scatter plot of random X and Y points.
3. Draw a bar chart showing the population of 5 different countries.
4. Plot a histogram of 1000 data points drawn from a normal distribution.
5. Add a title, X-label, and Y-label to a plot.

## Medium (🟡)
6. Create a 2x2 subplot grid and place 4 different types of plots in it.
7. Use Seaborn to plot a boxplot of a numerical column grouped by a categorical column from a DataFrame.
8. Generate a correlation matrix for a DataFrame and plot it using `sns.heatmap`.
9. Plot two lines on the same axes with different colors, markers, and a legend.
10. Customize a Seaborn plot's color palette to 'viridis' and set the style to 'darkgrid'.

## Hard (🔴)
11. Load the Iris dataset. Use `sns.pairplot` coloring the points by species.
12. Create a complex visualization combining a bar chart and a line plot on the same axes (twinx).
13. Plot a ROC curve given true labels and predicted probabilities, including the AUC score in the legend.
14. Create an annotated heatmap where specific cells are highlighted based on a threshold.
15. Write a function that takes a DataFrame and automatically plots histograms for all numerical columns and bar charts for all categorical columns, saving them to a folder.
