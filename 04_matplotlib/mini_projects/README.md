# 🚀 Mini Projects: Data Visualization

## 1. Interactive Dashboard Creator (Mock)
**Description:** Using Matplotlib and `ipywidgets` (in a Jupyter environment), create a simple interactive dashboard where changing a slider updates the parameters of a mathematical function (like frequency of a sine wave) and updates the plot dynamically.
**Skills:** Matplotlib OO API, basic interactiveness.

## 2. ML Results Visualizer
**Description:** Given a mock dataset of ML model predictions (True labels, Predicted labels, Probabilities), write a script that generates a comprehensive PDF report containing:
- A Confusion Matrix
- A ROC Curve with AUC
- A Precision-Recall curve
- A bar chart of feature importances
**Skills:** Classification metrics visualization, subplot layouts, saving figures.

## 3. Data Story Teller
**Description:** Find a dataset about a topic you care about (e.g., climate change, sports stats). Create a series of 3-5 high-quality, heavily customized plots that tell a progressive story. Focus on aesthetics: remove chart junk, use highlighting colors effectively, and add descriptive titles and annotations.
**Skills:** Customizing aesthetics, annotations, data storytelling.
