# 🚀 Intermediate Projects

These projects introduce more complex algorithms, messier datasets, and advanced evaluation techniques. 

## 1. Customer Churn Prediction
- **Description**: Predict which customers are likely to cancel their subscription service.
- **Dataset**: Telco Customer Churn dataset.
- **Key Skills**: Dealing with imbalanced classes, advanced tree models (XGBoost, LightGBM), evaluating with ROC-AUC and F1-Score, feature importance.
- **Estimated Time**: 5-8 hours.

## 2. Movie Recommendation System
- **Description**: Build a system that recommends movies to users based on their past viewing history or similarities between movies.
- **Dataset**: MovieLens dataset (100k or 1M).
- **Key Skills**: Collaborative filtering, matrix factorization (SVD), cosine similarity, evaluating recommender systems.
- **Estimated Time**: 6-10 hours.

## 3. Loan Approval Prediction
- **Description**: Automate the loan eligibility process based on customer detail provided while filling online application form.
- **Dataset**: Loan Prediction dataset.
- **Key Skills**: Advanced feature imputation, pipeline building, hyperparameter tuning via GridSearchCV or RandomizedSearchCV.
- **Estimated Time**: 5-7 hours.

## 4. Emotion Detection
- **Description**: Classify the emotion (joy, sadness, anger, etc.) expressed in a short piece of text (like a tweet).
- **Dataset**: Emotion dataset from HuggingFace/Kaggle.
- **Key Skills**: Word embeddings (Word2Vec or GloVe), recurrent neural networks (RNN/LSTM) using PyTorch, text tokenization.
- **Estimated Time**: 8-12 hours.
