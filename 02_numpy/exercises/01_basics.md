# 🏋️ Exercises: NumPy Basics

## Easy (🟢)
1. Create a 1D array of numbers from 0 to 9.
2. Create a 3x3 boolean array where all values are `True`.
3. Extract all odd numbers from an array `arr`.
4. Replace all odd numbers in `arr` with -1.
5. Create a 2D array of shape (5, 5) with 1 on the border and 0 inside.

## Medium (🟡)
6. Reshape a 1D array of size 10 into a 2D array of shape (2, 5).
7. Stack two arrays `a` and `b` vertically, then horizontally.
8. Get the common items between two python NumPy arrays.
9. Reverse the columns of a 2D array.
10. Create a 5x5 matrix with row values ranging from 0 to 4 using broadcasting.

## Hard (🔴)
11. Compute the Euclidean distance between two arrays `a` and `b`.
12. Find the index of the 5th maximum value in an array.
13. Normalize a 5x5 random matrix (subtract mean, divide by standard deviation).
14. Implement matrix multiplication using `np.einsum`.
15. Given a 1D array, compute the moving average of window size 3.
