# 🏋️ Exercises: Python Basics

## Easy (🟢)
1. Write a function that takes a list of numbers and returns a new list containing only the even numbers.
2. Create a dictionary storing a user's `name`, `age`, and `city`.
3. Use a list comprehension to generate squares of numbers from 1 to 10.
4. Write a script that reads a text file and prints its contents line by line.

## Medium (🟡)
5. Create a lambda function to convert Celsius to Fahrenheit. Apply it to a list of temperatures.
6. Write a class `Dataset` that initializes with a list of data points and has a method `get_summary()` returning the length.
7. Use the `collections.Counter` to find the most common word in a given string.
8. Implement a generator function that yields Fibonacci numbers up to `N`.
9. Write a try-except block to handle a `FileNotFoundError` gracefully.
10. Combine two lists into a dictionary using `zip`.

## Hard (🔴)
11. Write a decorator `@time_it` that prints the execution time of any function it wraps.
12. Create an abstract base class `Model` with a `train` method, and a subclass `LinearModel` that implements it.
13. Parse a nested JSON string into Python objects, modify a specific nested value, and serialize it back to JSON.
14. Implement a custom iterator class that returns batches of data of a specified `batch_size` from a given list.
15. Use `itertools` to generate all possible combinations of hyperparameters from a dictionary of lists.
