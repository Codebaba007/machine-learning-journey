# 🔒 Security Policy

## 🛡️ Security Policy

We take the security of this project seriously. While this is primarily an educational repository, any security vulnerabilities found in our code, dependencies, or deployed examples should be reported and handled responsibly.

## 📦 Supported Versions

Only the current main branch is supported with security updates. 

| Version | Supported          |
| ------- | ------------------ |
| `main`  | ✅ Yes              |
| `< 1.0` | ❌ No               |

## 🚨 How to Report Vulnerabilities

If you discover a security vulnerability within this project, please DO NOT create a public issue. 

Instead, please send an email to **Mehedi Hasan** at:
📧 **[mehedihassanbhuiyan241@gmail.com](mailto:mehedihassanbhuiyan241@gmail.com)**

Please include:
- The type of vulnerability
- The steps to reproduce the issue
- Potential impact

## ⏱️ Response Timeline
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will send you regular updates about our progress in addressing the issue.
- A fix will be developed and released as quickly as possible.

## 📢 Disclosure Policy
We will notify you when the issue has been patched. We ask that you do not share details of the vulnerability publicly until a fix has been released and the community has had a chance to update.
