# 🏋️ Machine Learning Exercises

Practice these exercises to solidify your understanding of ML fundamentals.

## Conceptual Questions
1. ⭐ Explain the difference between regression and classification.
2. ⭐ What is the purpose of a train/test split?
3. ⭐⭐ Explain the bias-variance tradeoff in your own words.
4. ⭐⭐ How do L1 and L2 regularization differ in their effect on model weights?
5. ⭐⭐⭐ Describe how a Random Forest classifier makes predictions compared to a single Decision Tree.

## Implementation Tasks (Scikit-learn)
6. ⭐ Load the Iris dataset using `sklearn.datasets` and split it into 80% training and 20% testing sets.
7. ⭐ Train a standard Logistic Regression model on the Iris training data and print the accuracy on the test data.
8. ⭐⭐ Apply StandardScaler to the features before training. Does it affect the results?
9. ⭐⭐ Implement a 5-fold cross-validation on a Decision Tree classifier using the breast cancer dataset.
10. ⭐⭐ Compare the performance (accuracy and F1-score) of a Support Vector Machine (SVM) and a Random Forest on a dataset of your choice.

## Advanced Tasks
11. ⭐⭐⭐ Write a custom feature transformer using `sklearn.base.BaseEstimator` and `TransformerMixin`.
12. ⭐⭐⭐ Build a Pipeline that includes imputation, scaling, and an XGBoost classifier.
13. ⭐⭐⭐ Perform hyperparameter tuning using `GridSearchCV` on a Random Forest model.
14. ⭐⭐⭐ Plot a ROC curve for a binary classification model and calculate the AUC.
15. ⭐⭐⭐ Implement a VotingClassifier combining at least three different model types.
